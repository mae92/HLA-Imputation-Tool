# HLA-Imputation-Tool

## A tool for 9-locus/11-gene high resolution HLA typing from low resolution molecular or serological typing. 
<img width="1280" height="720" alt="HLA_Imputation_Tool_Flowcharts_new" src="https://github.com/user-attachments/assets/da6e274d-ec24-4303-b021-b8473ca5e310" />

### Save all files as a Visual Studio project and you can build the exicutable .exe file or just run the program from Visual Studio.

### The haplotype reference file is incomplete because I cannot upload a 200Mb file to GitHub. You will need to download the data from this publication and format it in the same way the example reference file (A-C-B-DRB-DQ-DP_Haplotypes_Dataframe.csv) is formatted. Gragert L, et al., bioRxiv 2026.04.09.717537. All other reference files are fine as is.

### The python script included in this repo is for converting high resolution molecular typing into serological typing. Feel free to use if if you want to convert back to serological and test the accuracy of the algorithm in your population. Otherwise the settings in the application will allow you to drop to one field molecular and convert to g-group etc.
